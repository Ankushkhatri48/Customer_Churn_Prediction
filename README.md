# Customer Churn Prediction App with SHAP Explainability & LLM summaries

This application implements an end-to-end Machine Learning pipeline to predict customer churn using the public **Telco Customer Churn Dataset**. It features local and global feature attribution using **SHAP (SHapley Additive exPlanations)** and natural language summaries of predictions generated by the **Groq API** (`llama-3.3-70b-versatile`).

## Features
1. **Machine Learning Model**: Balanced Random Forest Classifier trained on cleaned customer demographics, account records, and services.
2. **Global Interpretability**: Live global SHAP summary plot shown in the app sidebar.
3. **Local Explainability**: Real-time customer churn predictions with custom color-coded matplotlib SHAP contribution charts.
4. **Natural Language Summaries**: Convert complex SHAP statistics into simple, human-friendly risk summaries using a high-performance Llama model via the Groq API.
5. **Premium Interface**: Polished dashboard built with Streamlit featuring responsive input forms, visual probability metrics, and clean card styling.

---

## Technical Architecture & Model Decisions

### 1. Dataset Cleaning
- **Missing Value Coercion**: Coerced empty space values in `TotalCharges` to NaN, filling them with the median of the dataset.
- **Categorical Processing**: Mapped and encoded categorical services and contracts using target-aligned Label Encoding, keeping the feature dimensions low and highly interpretable.

### 2. Modeling Choices
- **Random Forest Classifier**: Chosen for its robust non-linear boundary learning and direct out-of-the-box compatibility with Tree SHAP.
- **Imbalance Mitigation**: Addressed class imbalance using `class_weight='balanced'` within scikit-learn, yielding high Recall (Sensitivity) to capture churners.

### 3. Why SHAP?
Traditional feature importance only gives a single global rank. **SHAP** calculates Shapley values based on game theory, offering:
- **Consistency**: Features with greater impact are guaranteed to get larger SHAP attributions.
- **Additive Local Explanations**: Quantifies exactly how much each individual feature pushes a specific customer's risk probability above or below the baseline average risk.

## Project Structure
- `data_manager.py`: Connects to dataset URL, cleans records, applies encoders, and formats splits.
- `model.py`: Trains the Random Forest, prints precise F1/Recall/Precision metrics, and exports pickles.
- `explain.py`: Performs SHAP calculations and plot rendering.
- `llm.py`: Interfaces with Groq API models to produce natural language explanation cards.
- `app.py`: Streamlit UI code.
- `requirements.txt`: Python package dependencies list.

## Setup & Local Execution

### 1. Clone & Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Set Up Groq API Key
Obtain a free Groq API key from the [Groq Console](https://console.groq.com/).

#### Option A: Local environment variable
On Windows PowerShell:
```powershell
$env:GROQ_API_KEY="your_api_key_here"
```
On Linux/macOS:
```bash
export GROQ_API_KEY="your_api_key_here"
```

#### Option B: Streamlit Secrets
Create a `.streamlit/secrets.toml` file in the project folder:
```toml
GROQ_API_KEY = "your_api_key_here"
```

### 3. Train the Model (Optional)
The Streamlit app will automatically train and cache the model on its first run if `churn_model_assets.pkl` is missing. You can also run it manually:
```bash
python model.py
```

### 4. Run the Streamlit Dashboard
```bash
streamlit run app.py
```
